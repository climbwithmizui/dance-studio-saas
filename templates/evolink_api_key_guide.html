EVOLINK START GUIDE

EvoLink APIキーの取得方法

Dance Studioで動画を生成するには、ご自身のEvoLinkアカウント、APIキー、生成クレジットが必要です。

APIキーはパスワードと同じように扱ってください。
他人へ送ったり、SNSへ載せたりしないでください。APIキーはサポートへ送らないでください。
  1. EvoLinkのAPIキー管理画面を開く 下の公式リンクを開きます。ログインしていない場合は、登録またはログイン画面が表示されます。
    EvoLink APIキー管理画面を開く
  2. EvoLinkへ登録またはログインする 画面の案内に沿ってアカウントを準備します。登録済みなら、そのアカウントでログインしてください。
  3. API Keysで新しいキーを作成する ダッシュボードの「API Keys」を開き、「Create New Key」などの新規作成ボタンを押します。画面名はEvoLinkの更新で変わる場合があります。
  4. 表示されたAPIキーをコピーする コピーしたキーは安全な場所へ保管します。キーそのものをこのマニュアルや問い合わせ文へ貼り付けないでください。
  5. Dance Studioへ貼り付ける Dance Studioの「STEP 1 EvoLink APIキー」欄へ貼り付けます。前後に空白が入らないよう確認してください。
    Dance Studioを開く
  6. 生成前にクレジット残高を確認する Dance Studioの月額料金にEvoLinkクレジットは含まれません。不足している場合は、EvoLink側で追加してください。
    EvoLinkの請求・残高画面を開く

APIキーの保存と削除

Dance Studioは、入力したキーを現在使用しているブラウザ内に保存します。生成処理中はサーバーへ送信されますが、生成完了または失敗後に一時データから削除されます。

共用端末を使った場合は、Dance Studio画面の「この端末からAPIキーを削除」を必ず押してください。

うまくいかないとき

「APIキーが無効です」と表示される

  • コピー時に前後の空白が入っていないか確認します。
  • EvoLinkのAPI Keys画面で、キーが有効か確認します。
  • 解決しない場合は、EvoLinkで新しいキーを作成して入れ直します。

クレジット不足と表示される

EvoLinkの残高を追加し、反映後にもう一度生成してください。Dance Studioが自動的に安い生成方式へ切り替えることはありません。

EvoLinkの画面構成やボタン名は変更されることがあります。見つからない場合は、公式ダッシュボード内の「API Keys」またはキー管理メニューを探してください。

確認元：EvoLink公式ダッシュボード・公式APIドキュメント（2026年9月3日確認）
